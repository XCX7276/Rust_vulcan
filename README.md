# Parodia

Воксельная RPG-выживалка с бесконечным генерируемым миром. Свой движок: Rust + Vulkan 1.3 (`ash`).
Техзадание: `..\claude\03_промпт_для_своей_игры.md`.

## Что нужно на компьютере

- Rust (stable) — https://rustup.rs
- Vulkan SDK (LunarG) — для компилятора шейдеров `glslc` и проверки ошибок Vulkan
- Видеокарта с Vulkan 1.3 и свежий драйвер

## Сборка и запуск (PowerShell)

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo run
```
Отладочная сборка: включена проверка ошибок Vulkan, видна консоль с журналом.

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo run --release
```
Финальная сборка: максимальная скорость, без консоли. Готовый файл — `target\release\parodia.exe`.

## Тесты

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo test
```
Проверяют координаты (в том числе отрицательные и дальние ±1 000 000), хранение чанков, реестр блоков,
шум и генератор (одинаковый мир при одном зерне, совпадение на границах чанков), построение мешей
и распределитель места в пуле геометрии.

## Работа без интернета

Интернет нужен только при первой сборке и при добавлении новой библиотеки: Cargo скачивает
библиотеки в свой кеш (`%USERPROFILE%\.cargo\registry`). Дальше можно собирать без сети:
```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo build --offline
```

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | захватить мышь (управление камерой) |
| Esc | отпустить мышь |
| Мышь | обзор |
| W A S D | полёт вперёд / влево / назад / вправо |
| Пробел / левый Ctrl | вверх / вниз |
| Shift | быстрее (×6) |
| F3 | показать / скрыть экран отладки |
| `[` / `]` | время суток на 15 минут назад / вперёд (можно держать) |
| `−` / `=` | медленнее / быстрее ход времени (×1 … ×128) |
| P | пауза времени |
| `;` / `'` | склонение пути солнца и луны на 5° меньше / больше (0–60°) |
| `G` | сетка карты теней: по рёбрам блоков / квадратная «с солнца» (для сравнения) |

## Флаги окружения (PowerShell)

Пример: `$env:PARODIA_VSYNC="0"; cargo run --release`. Сбросить: `Remove-Item Env:PARODIA_VSYNC`.

| Флаг | Значения | Что делает |
|---|---|---|
| `PARODIA_VSYNC` | `1` (по умолч.) / `0` | вертикальная синхронизация; `0` — для замеров FPS |
| `PARODIA_VALIDATION` | `1` / `0` | проверка ошибок Vulkan (по умолчанию включена только в отладочной сборке) |
| `PARODIA_LANG` | `ru` (по умолч.) / `en` | язык интерфейса |
| `PARODIA_LOG` | `info` (по умолч.) / `debug` / `trace` / `warn` / `error` | подробность журнала |
| `PARODIA_SEED` | число (по умолч. `1337`) | зерно мира |
| `PARODIA_RADIUS` | 1–48 (по умолч. `8`) | радиус загрузки мира по горизонтали, в чанках |
| `PARODIA_VRADIUS` | 1–32 (по умолч. `4`) | окно загрузки по высоте вокруг камеры, в чанках |
| `PARODIA_WORKERS` | 1–32 (по умолч. ядра − 2, не больше 6) | рабочих потоков генерации и построения моделей |
| `PARODIA_LOD_LEVELS` | 0–4 (по умолч. `4`) | уровней упрощённого дальнего мира (2, 4, 8, 16 м); `0` — без LOD, дальность = радиус |
| `PARODIA_FACE_CULLING` | `1` (по умолч.) / `0` | отсечение граней, повёрнутых от камеры (и задних треугольников, и целых групп сторон чанка) |
| `PARODIA_FRUSTUM_CULLING` | `1` (по умолч.) / `0` | не рисовать чанки вне поля зрения камеры |
| `PARODIA_OCCLUSION_CULLING` | `1` (по умолч.) / `0` | не рисовать чанки, закрытые горой или стеной (Hi-Z) |
| `PARODIA_SHADOWS` | `1` (по умолч.) / `0` | тени от солнца и луны |
| `PARODIA_SHADOW_SIZE` | 256–8192 (по умолч. `2048`) | сторона карты теней одного каскада |
| `PARODIA_SHADOW_GRID` | `blocks` (по умолч.) / `sun` | оси карты теней: по рёбрам блоков (края теней прямые при любом склонении) или прежние квадратные |
| `PARODIA_AO` | `1` (по умолч.) / `0` | затенение углов и стыков блоков |
| `PARODIA_SUN_SIZE`, `PARODIA_MOON_SIZE` | градусы, 0.2–20 (по умолч. `2.5`) | размер солнца и луны на небе (пиксельные диски 16×16) |
| `PARODIA_TIME` | часы (по умолч. `9`, можно `18.5`) | время суток при запуске |
| `PARODIA_DAY_MINUTES` | минуты (по умолч. `20`; `0` — время стоит) | длина суток в реальных минутах |
| `PARODIA_SUN_TILT` | градусы 0–60 (по умолч. `0`) | склонение пути солнца и луны: в полдень солнце на 90° − склонение; тени рёбер вдоль X и Z всегда прямые, наискосок идут только тени вертикальных рёбер |
