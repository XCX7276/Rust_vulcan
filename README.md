# Parodia

Воксельная RPG-выживалка с бесконечным генерируемым миром. Свой движок: Rust + Vulkan 1.3 (`ash`).
Техзадание: `..\claude\03_промпт_для_своей_игры.md`.

## Что нужно на компьютере

- Rust (stable) — https://rustup.rs
- Vulkan SDK (LunarG) — для компилятора шейдеров `glslc` и проверки ошибок Vulkan
- Видеокарта с Vulkan 1.3 и свежий драйвер

## Сборка и запуск (PowerShell)

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo run
```
Отладочная сборка: включена проверка ошибок Vulkan, видна консоль с журналом.

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo run --release
```
Финальная сборка: максимальная скорость, без консоли. Готовый файл — `target\release\parodia.exe`.

## Тесты

```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo test
```
Проверяют координаты (в том числе отрицательные и дальние ±1 000 000), хранение чанков, реестр блоков,
шум и генератор (одинаковый мир при одном зерне, совпадение на границах чанков), построение мешей
и распределитель места в пуле геометрии.

## Работа без интернета

Интернет нужен только при первой сборке и при добавлении новой библиотеки: Cargo скачивает
библиотеки в свой кеш (`%USERPROFILE%\.cargo\registry`). Дальше можно собирать без сети:
```
cd C:\Users\xcx7276\Desktop\proj\parodia
cargo build --offline
```

## Флаги окружения (PowerShell)

Пример: `$env:PARODIA_VSYNC="0"; cargo run --release`. Сбросить: `Remove-Item Env:PARODIA_VSYNC`.

| Флаг | Значения | Что делает |
|---|---|---|
| `PARODIA_VSYNC` | `1` (по умолч.) / `0` | вертикальная синхронизация; `0` — для замеров FPS |
| `PARODIA_VALIDATION` | `1` / `0` | проверка ошибок Vulkan (по умолчанию включена только в отладочной сборке) |
| `PARODIA_LANG` | `ru` (по умолч.) / `en` | язык интерфейса |
| `PARODIA_LOG` | `info` (по умолч.) / `debug` / `trace` / `warn` / `error` | подробность журнала |
| `PARODIA_SEED` | число (по умолч. `1337`) | зерно мира |
| `PARODIA_RADIUS` | 1–48 (по умолч. `8`) | радиус загрузки мира в чанках |
| `PARODIA_FACE_CULLING` | `1` (по умолч.) / `0` | отсечение задних граней (выключить — для отладки) |
