# Производительность Parodia

Правило: сначала замер, потом изменение, потом повторный замер на той же сцене.
Без замера ускорение не заявляется.

Целевая машина: Ryzen 5 PRO 4650G, встроенная Radeon (Vega), 16 ГБ, Windows 10.
Цель: ≥ 60 FPS в 1080p на средних настройках.

## Как мерить

```
cd C:\Users\xcx7276\Desktop\proj\parodia
$env:PARODIA_VSYNC="0"; $env:PARODIA_VALIDATION="0"; cargo run --release
```
Цифры — на экране F3 и в журнале `%APPDATA%\Parodia\logs\latest.log`: раз в 10 секунд строка
`perf: <FPS> fps, frame <мс> (worst <худший кадр>), cpu <мс>, wait <мс>, gpu <мс>, draws <N>, quads <N>, chunks <нарисовано>/<в поле зрения> (occluded <закрыто>), shadows <каскадов за кадр> cascades <квадов в тенях> quads, upload <МБ/с>, <ширина>x<высота>` — средние за 10 секунд.
`cpu` — работа главного потока без ожидания; `wait` — ожидание видеокарты и монитора.

Для замеров отсечения «до/после» — те же условия, но с флагами `PARODIA_FRUSTUM_CULLING=0`,
`PARODIA_OCCLUSION_CULLING=0`, `PARODIA_FACE_CULLING=0` по очереди (после замера сбросить:
`Remove-Item Env:<имя>`). Смотреть `gpu`, `quads` и `chunks`.

Для замеров стриминга: стоять на месте (сцена устоялась) и отдельно лететь по прямой (Shift + W),
смотреть `worst` (рывки) и строку F3 «Потоки» — очередь не должна расти без конца.
