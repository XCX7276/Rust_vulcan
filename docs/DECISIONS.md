# Решения Parodia

Здесь записывается, что и почему решено, и все временные места (`TEMPORARY:` в коде).

## Принятые решения

| № | Решение | Почему |
|---|---|---|
| 1 | Свой движок: Rust + Vulkan 1.3 через `ash`, окно `winit` | полный контроль над рендером и оптимизацией; путь проверен Arivel |
| 2 | Без mesh shaders; vertex pulling + indirect draw + compute-отсечение | встроенная Vega их не поддерживает |
| 3 | Dynamic rendering + synchronization2 (Vulkan 1.3) | меньше кода, чем render pass/framebuffer, понятнее барьеры |
| 4 | 2 кадра в полёте | процессор и видеокарта работают параллельно, задержка минимальная |
| 5 | Семафор «дорисовано» — на каждую картинку swapchain, а не на кадр | иначе семафор может переиспользоваться, пока его ещё ждёт показ |
| 6 | egui — только для экрана отладки F3 | быстро и надёжно; игровой интерфейс будет свой, пиксельный |
| 7 | Версии библиотек: ash 0.38, winit 0.30, gpu-allocator 0.28, egui 0.36, egui-ash-renderer 0.13 | проверенно совместимый набор |
| 8 | Свой простой журнал (`parodia-core::logging`) вместо готового | одна зависимость меньше; пишет и в консоль, и в файл |
| 9 | Ошибки — `anyhow` | короткий код и цепочки причин в журнале |
| 10 | Тексты интерфейса — только в `assets/lang/*.json`, встраиваются в exe | в коде нет русского; переводы не теряются |
| 11 | Офлайн-сборка — через кеш Cargo (`cargo build --offline`) | `cargo vendor` скачал бы библиотеки для всех ОС (сотни МБ); при необходимости включим позже |
| 12 | Чанк хранится как «однородный» или «палитра + упакованные номера» (1/2/4/8/16 бит) | подземелье и небо — однородные чанки почти без памяти; ширина — степень двойки, номер не пересекает слово u64 |
| 13 | Реестр блоков из JSON, разбор через `serde_json::Value` без `serde`-макросов | данные отдельно от кода, на одну зависимость меньше |
| 14 | Квад = 8 байт, vertex pulling, без вершинного буфера | в 4–8 раз меньше памяти и трафика, чем вершины с float-координатами; важно для встроенной Vega |
| 15 | Один пул геометрии на все чанки + слот чанка через `firstInstance` | один набор привязок на весь ландшафт; формат вызова совпадает с indirect-отрисовкой (этап 5) |
| 16 | Позиция камеры: целая часть + дробная; камера для GPU в начале координат | точность не падает вдали от центра мира |
| 17 | Обратная бесконечная глубина (reverse-Z), D32_SFLOAT | максимальная точность глубины на больших расстояниях, нет дальней плоскости |
| 18 | Шейдеры компилируются при сборке (`build.rs` + glslc из Vulkan SDK) | ошибка в шейдере видна сразу при сборке; SPIR-V встраивается в exe |
| 19 | Комментарии в шейдерах — на английском, пояснения к ним — в `docs/ARCHITECTURE.md` | компилятор шейдеров может не принять кириллицу в исходнике |
| 20 | Меш строится только когда сгенерированы все 6 соседей | нет лишних стенок на стыках и краях; не нужно перестраивать модель при появлении соседа |
| 21 | Свой пул потоков (std: Mutex + Condvar + mpsc), без сторонних библиотек | простая и понятная очередь по приоритету; состояние на поток (свой `Mesher`) |
| 22 | Лимит заданий «в полёте» = потоки × 4 вместо отмены заданий | при быстром полёте очередь не растёт; устаревшие результаты отбрасываются по версии |
| 23 | По высоте грузится полоса поверхности + окно вокруг камеры | поверхность видна с любой высоты; под землёй не грузится небо, на горе — глубина |
| 24 | Загрузка мешей — через промежуточный буфер на каждый кадр в полёте, копирование в командах кадра | процессор не ждёт видеокарту; бюджет 8 МБ за кадр ограничивает рывки |
| 25 | «Время процессора» в F3 — без ожидания видеокарты и монитора; ожидание показывается отдельно | при VSync ожидание иначе выглядело бы как нагрузка |

## Временные места (TEMPORARY)

| Где | Что | Чем заменится |
|---|---|---|
| `parodia-world/src/generator.rs` | генератор — простая карта высот (камень, 3 слоя земли, трава) | этап 11: слои (континенты, хребты, эрозия, климат, биомы…), интерфейс тот же |
| `shaders/terrain.frag`, `assets/data/blocks.json` (`color`) | плоский цвет на блок вместо текстур | текстуры блоков 16 px (массив текстур) |
| `parodia-app/src/app.rs` (`SUN_DIRECTION`) | неподвижное солнце | этап 7: смена суток, тени |
